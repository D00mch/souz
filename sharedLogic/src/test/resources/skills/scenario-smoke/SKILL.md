# Регистрация результата

Возьми идентификатор заявки из запроса пользователя.

1. Получи схему Skill `RecordScenarioResult` через доступный discovery tool.
2. Вызови `RunSkillCommand` с `skillId` равным `RecordScenarioResult`.
3. В `arguments` передай `requestId` с идентификатором заявки и `value` со строкой `skill-framework-ok`.
4. После успешной регистрации коротко сообщи пользователю результат.

Этот Skill описывает процедуру. Для её выполнения используй указанный тул.
