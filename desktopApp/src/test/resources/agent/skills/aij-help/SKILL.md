# Справка по конференции AI Journey

Скилл ищет ответ в базе знаний конференции AI Journey (aij.ru) и возвращает материал, из
которого ты формулируешь ответ сам.

**Вызывай инструмент RunSkillCommand с такими параметрами:**
- `skillId` — id этого скилла из контекста активации
- `runtime = BASH`
- `scriptPath = scripts/help.sh`
- `args` — массив из одного элемента: вопрос пользователя целиком, своими словами
- `timeoutMillis` — 45000

Не копируй и не пересказывай содержимое скрипта в параметр `script` — только `scriptPath` + `args`, backend сам подставит содержимое файла.

## Что возвращает скрипт

- `RELEVANCE=0.77` — насколько база знаний покрывает вопрос;
- `MATERIAL: ...` — факты по конференции: даты, формат, программа, треки, участие;
- `SECTION⇥заголовок` — раздел базы, откуда взято (постраничных ссылок у статей нет,
  поэтому URL не выводится — он всегда один и тот же, aij.ru);
- `NO_ANSWER` — в базе знаний ничего нет;
- строка с `Error:` — сервис недоступен.

## Как формулировать ответ

`MATERIAL` — это выжимка из общей базы, а не реплика для пользователя. Перескажи её:

- говори на «ты», живой речью, без канцелярита;
- даты произноси словами: «с двадцать пятого по двадцать седьмое ноября», не «25–27.11»;
- имена и названия треков переноси точно, их не пересказывай своими словами;
- голосом — два-четыре факта по существу вопроса, не вываливай всё сразу;
- если спросили про одно (например даты), не пересказывай программу целиком;
- то, чего нет в материале, не выдавай за официальную информацию о конференции.

Голосом коротко. В переписке можно подробнее и со ссылкой на aij.ru.

## Когда база не подходит

`RELEVANCE` ниже 0.6 или `NO_ANSWER` — вопрос не про конференцию AI Journey. Сервис и
тогда отвечает уверенно, но мимо: скажи, что в справке конференции этого нет.

Это не справка по устройствам Сбера: вопросы про колонку, приставку или телевизор к
конференции отношения не имеют. Расписание самого пользователя — это календарь.
