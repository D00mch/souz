# Huawei Health

Читай данные о здоровье пользователя из Huawei Health. Сам API
(`health-api.cloud.huawei.com`) вызывается инструментом `SafeApiCall` — токен
подставляет бэкенд, скрипт скилла его никогда не видит и сам в сеть не ходит.
Скрипт (`scripts/hh_api.sh`) нужен только для локальной работы с JSON: собрать
тело запроса с нужными метками времени и разобрать ответ в читаемый вид.

Скилл только читает данные. Ничего не записывает и не удаляет.

## Если аккаунт ещё не подключён

Если `SafeApiCall` вернул `reconnectRequired: true`:
- Если есть уверенность, что пользователь сейчас видит текст (переписка,
  экран) — покажи `authorizationUrl` как есть (это ссылка, которую нужно
  открыть в браузере и подтвердить доступ), и попроси повторить исходную
  команду после подтверждения.
- Если разговор идёт только голосом, без экрана (или нет уверенности, что
  пользователь видит текст) — **не проговаривай `authorizationUrl` вслух**.
  Вместо этого скажи, что для первого подключения аккаунта Huawei нужно
  написать боту в Telegram или открыть приложение souz — по голосовой команде
  это не делается, потому что нужен браузер.

## Метрики

| Метрика | Что это | Как отвечать |
|---|---|---|
| `steps` | шаги | суммируй за день (`sum`) |
| `heart-rate` | пульс, мгновенные замеры | среднее/мин/макс (`avg`, `min`, `max`) |
| `heart-rate-continuous` | пульс, непрерывный ряд | среднее/мин/макс |
| `stress` | уровень стресса | среднее и максимум |
| `sleep` | детализация сна | используй `parse-sleep`, а не `parse-daily` |

Кислород в крови (SpO2) и температура кожи **недоступны** — приложению не
выданы соответствующие разрешения Huawei. Если о них спросят, скажи, что этот
тип данных сейчас не подключён, и не пытайся запросить его через `SafeApiCall`.

`bash scripts/hh_api.sh metrics` печатает эту таблицу с точными
`dataTypeName` — вызывай, если нужно свериться.

## Как прочитать метрику за период

1. Собери тело запроса — `RunSkillCommand` (`skillId`, `runtime = BASH`), без `stdin`:

   `script = "bash scripts/hh_api.sh build-body <метрика> <YYYY-MM-DD> [<YYYY-MM-DD>]"`

   Одна дата — этот день целиком. Две — период включительно (вторая дата
   входит в интервал). Даты считаются в часовом поясе `+03:00`; чтобы задать
   другой, добавь четвёртым аргументом смещение вида `+05:00`.

2. Вызови `SafeApiCall`:
   - `skillId` — ID этого скилла
   - `method = "POST"`
   - `url = "https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:polymerize"`
   - `headers = {"Content-Type": "application/json"}`
   - `body` — то, что вернул шаг 1

3. Возьми из ответа `SafeApiCall` поле `body` (это JSON-текст) и передай его
   как `stdin` в `RunSkillCommand` (`runtime = BASH`):

| Что нужно | script |
|---|---|
| Итоги по дням: сумма, среднее, мин, макс, число замеров | `bash scripts/hh_api.sh parse-daily` |
| Все замеры подряд (время + значение) | `bash scripts/hh_api.sh parse-samples` |
| Сон по стадиям и итог за ночь | `bash scripts/hh_api.sh parse-sleep` |

Для `parse-daily` и `parse-sleep` можно задать часовой пояс вторым
аргументом (`bash scripts/hh_api.sh parse-daily +05:00`), по умолчанию `+03:00`.

Отвечай пользователю тем числом, которое указано в колонке «Как отвечать»
таблицы метрик: для шагов это сумма за день, для пульса — среднее с
диапазоном, а не сырой список замеров. Список замеров (`parse-samples`) бери
только если спросили про конкретное время или динамику внутри дня.

## Как посмотреть тренировки

1. `SafeApiCall`:
   - `method = "GET"`
   - `url = "https://health-api.cloud.huawei.com/healthkit/v2/activityRecords?startTime=<нач>&endTime=<кон>"`

   Границы — epoch в миллисекундах. Получить их для дат:
   `bash scripts/hh_api.sh range <YYYY-MM-DD> [<YYYY-MM-DD>]` — выведет
   `startTime` и `endTime`.

2. Ответ (`body`) передай как `stdin` в `RunSkillCommand`:
   `script = "bash scripts/hh_api.sh parse-workouts"`.

## Важно про даты

Huawei отдаёт метки времени в миллисекундах epoch. Никогда не считай их
вручную и не подставляй в запрос «на глаз» — всегда получай границы через
`build-body` или `range`. Если пользователь говорит «вчера», «за неделю»,
«за последние 3 дня» — сначала определи конкретные календарные даты, потом
передай их скрипту.

Если пользователь не назвал период — считай, что речь про сегодня.

## Ошибки

- `reconnectRequired: true` — см. раздел «Если аккаунт ещё не подключён».
- `403` от `health-api.cloud.huawei.com` — приложению не выдан нужный scope
  на стороне Huawei. Это не чинится переподключением: скажи пользователю, что
  для этого типа данных нужно отдельное разрешение в консоли разработчика
  Huawei, и назови метрику, которая не открылась.
- `401` при уже подключённом аккаунте — токен на стороне Huawei мог быть
  отозван; предложи переподключить аккаунт.
- Пустой результат (`parse-daily` ничего не вывел) — это не ошибка. Данных за
  этот период просто нет: часы могли не синхронизироваться с приложением
  Huawei Health, или пользователь их не носил. Так и скажи, не выдумывай числа.
- Данные старше недели могут быть недоступны — у скилла запрошен scope
  `historydata.open.week`. Если нужен год, это отдельное разрешение Huawei.
- Если пользователь спрашивает про SpO2 или температуру — см. примечание под
  таблицей метрик: эти данные не подключены, запрашивать их не нужно.
