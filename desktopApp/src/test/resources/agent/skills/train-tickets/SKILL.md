# Поезда (Туту)

Скилл берёт расписание прямых поездов из открытых данных Туту и возвращает компактные строки,
из которых ты формулируешь ответ сам. Цены и места на дату показывает только Туту,
ссылка ведёт прямо на выбор мест в нужном поезде.

**Вызывай инструмент RunSkillCommand с такими параметрами:**
- `skillId` — id этого скилла из контекста активации
- `runtime = BASH`
- `scriptPath = scripts/trains.sh`
- `args` — массив флагов и значений (см. ниже)
- `timeoutMillis` — 40000

Не копируй и не пересказывай содержимое скрипта в параметр `script` — только `scriptPath` + `args`,
backend сам подставит содержимое файла.

## Аргументы

| Аргумент | Что значит |
|---|---|
| `--from <город>` | откуда, в именительном падеже: «Москва», «Питер», «Нижний Новгород». Обязателен |
| `--to <город>` | куда. Обязателен |
| `--date <YYYY-MM-DD>` | дата поездки: ссылки откроют места на эту дату |
| `--after <ЧЧ:ММ>` / `--before <ЧЧ:ММ>` | отправление не раньше / не позже |
| `--overnight` | только ночные поезда, прибытие на следующий день |
| `--class <класс>` | только поезда с таким вагоном: `плацкарт`, `купе`, `СВ`, `люкс`, `сидячий` |
| `--name <название>` | только поезда с таким названием: `Сапсан`, `Ласточка`, `Красная стрела` |
| `--sort duration` | сначала самые быстрые; по умолчанию по времени отправления |
| `--limit <N>` | сколько поездов вернуть, по умолчанию 5 |

Примеры `args`:
- «поезда в Питер на десятое октября утром» → `["--from", "Москва", "--to", "Санкт-Петербург", "--date", "2026-10-10", "--after", "06:00", "--before", "12:00"]`
- «ночной поезд до Казани в пятницу, купе» → `["--from", "Москва", "--to", "Казань", "--date", "<ближайшая пятница>", "--overnight", "--class", "купе"]`
- «когда ближайший Сапсан» → `["--from", "Москва", "--to", "Санкт-Петербург", "--name", "Сапсан", "--date", "<сегодня>", "--after", "<сейчас>"]`
- «как быстрее доехать до Нижнего на поезде» → `["--from", "Москва", "--to", "Нижний Новгород", "--sort", "duration", "--limit", "3"]`

Даты («в пятницу», «на выходные», «послезавтра») переводи в `YYYY-MM-DD` сам по текущей дате из
контекста. Нет даты — вызывай без `--date`, не переспрашивай. Не назван город отправления —
возьми город пользователя из памяти, если он известен, иначе уточни одним вопросом.
Утро — 06:00–12:00, день — 12:00–17:00, вечер — после 17:00.

## Что возвращает скрипт

Строки с табуляцией как разделителем:

- `ROUTE⇥откуда⇥куда⇥дата|any⇥сколько поездов подходит` — что искали;
- `TRAIN⇥отправление⇥прибытие⇥в пути⇥номер⇥название|-⇥вокзалы⇥типы вагонов⇥ссылка` — поезд.
  Время московское. `+1` у прибытия — на следующий день, `+2` — через день;
- `LINK_ALL⇥ссылка` — все поезда направления на Туту (на дату, если она была);
- `PRICE_FLOOR⇥…` — самая низкая цена, которая бывала на направлении по типам вагонов.
  Это **не цена на дату**: при проверке реальные цены на дату через две недели были в 3–10 раз выше;
- `STATION⇥что сказал пользователь⇥что нашлось` — город подобран по похожему названию:
  если это неочевидно, переспроси;
- `STATION_UNKNOWN⇥запрос⇥похожие` — станция не найдена: уточни город;
- `NO_TRAINS⇥…` — прямых поездов нет;
- `NO_MATCH⇥…` — поезда есть, но под фильтры не подошли: предложи смягчить условия;
- `NOTE⇥…` — напоминание про расписание и цены;
- строка с `Error:` — сервис недоступен или дата в прошлом.

## Если транспорт не назван

«Как добраться до Казани», «хочу съездить в Питер на выходные» — человек не сказал, поезд или
самолёт. Вызови и этот скилл, и скилл авиабилетов `avia-tickets` с теми же городами и датой, потом
сравни одной-двумя фразами: сколько в пути на поезде и на самолёте, удобное время, цена самолёта.
Цену поезда на дату по-прежнему не называй. Если назван только поезд — вызывай только этот скилл.

## Как отвечать

- В Телеграме пиши простым текстом: без звёздочек, решёток и ссылок вида [текст](адрес) — Телеграм их не отображает. Ссылку ставь как есть, отдельной строкой.
- Говори обычными словами. Не используй «живые цены», «кэш», «планка», «выдача», «скилл», «на момент поиска» — так люди не говорят.
- Голосом коротко: два-три подходящих поезда. Для каждого — во сколько отправляется и
  прибывает, сколько в пути, название, если есть. «Сапсан в семь двадцать, в Питере в
  одиннадцать тридцать, четыре часа в пути». Не зачитывай ссылки, номера поездов и вокзалы,
  если о них не спросили.
- Прибытие с `+1` называй «на следующий день утром/днём»: «отправление в девять вечера,
  прибытие на следующий день в восемь утра».
- Длительность — по-человечески: «около четырёх часов», «почти сутки», «сутки и два часа».
- **Цену на дату не называй — скилл её не знает.** Если спрашивают, сколько стоит, скажи
  честно: точная цена и места — на Туту по ссылке, а самые дешёвые билеты на этом направлении
  бывают от `PRICE_FLOOR`, но ближе к дате обычно заметно дороже. Не выдавай `PRICE_FLOOR`
  за цену конкретного поезда.
- В конце одной фразой предложи прислать ссылку. Если человек согласен или спрашивает голосом
  про билеты — отправь ссылки текстом через `SendMessageToChannel` в telegram: по ссылке на
  каждый названный поезд и `LINK_ALL`.
- В переписке (Telegram) списком: время, в пути, название, типы вагонов и под каждым поездом его
  ссылка из строки `TRAIN` — она открывает выбор мест в этом поезде. `LINK_ALL` — только в конце.
- Без даты ссылки открывают расписание направления. Если человек хочет выбрать места —
  спроси дату и вызови скилл ещё раз с `--date`.
- `NO_TRAINS` — скажи, что прямых поездов нет, и предложи вариант: с пересадкой в крупном
  городе или самолёт через скилл `avia-tickets`.
- `Error:` — скажи, что расписание поездов сейчас недоступно, без технических деталей.

## Ограничения

- Только прямые поезда по России и расписание, без цен и мест на дату.
- Не каждый поезд ходит каждый день, время может сдвигаться на несколько минут: на дату
  точное расписание — на Туту.
- Скилл не покупает и не бронирует билеты. Если просят купить — дай ссылку, покупка на Туту.
- Самолёты — скилл `avia-tickets`, отели — скилл `hotel-search`. Электрички и автобусы скилл не ищет.
