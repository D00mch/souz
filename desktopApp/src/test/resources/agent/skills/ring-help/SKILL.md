# Справка по умному кольцу Сбера

Ищи сведения об устройстве и приложении в продуктовой справке Гигасправки. Скрипт ограничивает поиск параметром `productIds: ["ring"]`.

## Вызов

Вызывай `RunSkillCommand`:
- `skillId` — id этого скилла из контекста активации;
- `runtime = BASH`;
- `scriptPath = scripts/help.sh`;
- `args` — массив из одного элемента: вопрос о продукте;
- `timeoutMillis = 45000`.

Передавай `scriptPath` и `args`, не копируй скрипт в параметр `script`. Задавай справке общий вопрос об устройстве: личные показания и симптомы пользователя ей не нужны.

## Результат

- `RELEVANCE` — оценка соответствия найденного материала вопросу;
- `MATERIAL` — выжимка фактов из справки;
- `SOURCE` — заголовок и ссылка на источник;
- `NO_ANSWER` — материал отсутствует;
- `Error:` — ошибка доступа или сервиса.

Отвечай по существу вопроса, используя только подтверждённые материалом сведения. В текстовом ответе указывай ссылку на источник, когда он подтверждает ответ. Не переноси характеристики других устройств на кольцо. Если материал не покрывает конкретное условие, число, срок или гарантию, прямо обозначь этот пробел. Низкая релевантность — повод проверить соответствие материала, а не доказательство отсутствия свойства у устройства.

Справка описывает продукт, но не предоставляет текущие данные пользователя. Личные показатели получай через `ring-health`; описание метрики в справке не делает её доступной в API. Не вычисляй недоступные показатели по общему продуктовому описанию. Справка не является основанием для диагноза и не должна задерживать ответ о срочной помощи при опасных симптомах.
