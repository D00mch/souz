# Отели (Островок)

Скилл ищет варианты на Островке с актуальными ценами на даты и возвращает компактные строки, из
которых ты формулируешь ответ сам. Требования пользователя передавай флагами: скилл применяет
их прямо в поиске Островка, а не фильтрует готовый список.

**Вызывай инструмент RunSkillCommand с такими параметрами:**
- `skillId` — id этого скилла из контекста активации
- `runtime = BASH`
- `scriptPath = scripts/ostrovok.sh`
- `args` — массив флагов и значений (см. ниже)
- `timeoutMillis` — 40000

Не копируй и не пересказывай содержимое скрипта в параметр `script` — только `scriptPath` + `args`,
backend сам подставит содержимое файла.

## Аргументы

Всё, что человек говорит про жильё, переводи в флаги: скилл применяет их прямо в поиске Островка.

**Где и когда**

| Аргумент | Что значит |
|---|---|
| `--city <город>` | город в именительном падеже. Обязателен |
| `--checkin <YYYY-MM-DD>` / `--checkout <YYYY-MM-DD>` | заезд (обязателен) и выезд; без выезда — одна ночь |
| `--near <место>` | рядом с конкретным местом: станция метро, вокзал, аэропорт, достопримечательность. «у Павелецкого вокзала» → `--near "Павелецкий вокзал"`, «рядом с метро Маяковская» → `--near "Маяковская"`, «у Красной площади», «возле Шереметьево». Варианты сразу идут от ближнего к дальнему |
| `--radius <км>` | не дальше стольких километров: от `--near`, а без него от центра города. «в пешей доступности» → `1`, «совсем рядом» → `0.5` |
| `--district <район>` | район города по названию: «в Замоскворечье», «на Васильевском», «в центре Москвы» |
| `--metro` | просто рядом с любым метро |

**Кто едет**

| Аргумент | Что значит |
|---|---|
| `--adults <N>` | взрослых, по умолчанию 2 |
| `--children <возрасты>` | дети, через запятую возраст каждого: «с детьми пяти и девяти лет» → `5,9`. Возраст не назван — спроси |
| `--rooms <N>` | сколько номеров, если едут компанией: «две семьи», «нужно два номера» |

**Цена и порядок**

| Аргумент | Что значит |
|---|---|
| `--price-min` / `--price-max <₽>` | цена **за ночь**: «до 5 тысяч за ночь» → `--price-max 5000` |
| `--total-min` / `--total-max <₽>` | цена **за всё время**: «уложиться в 20 тысяч за поездку» → `--total-max 20000` |
| `--sort cheap` | «подешевле», «бюджетно» |
| `--sort expensive` | «самый дорогой», «люкс, ни в чём себе не отказывать» |
| `--sort rating` | «хороший», «с отличными отзывами», «самый лучший» |
| `--sort center` | «поближе к центру» (если назван `--near`, порядок и так от ближнего) |

**Какое жильё**

| Аргумент | Что значит |
|---|---|
| `--type <тип>` | `hotel` (отель, гостиница), `apartment` (квартира, апартаменты), `hostel`, `guesthouse` (гостевой дом), `sanatorium`, `resort` (курорт), `cottage` (коттедж, вилла, дом), `glamping` (глэмпинг, кемпинг) |
| `--stars <список>` | звёзды: «четыре-пять звёзд» → `--stars 4,5` |
| `--min-rating <5–9>` | рейтинг гостей не ниже: «рейтинг от восьми» → `--min-rating 8` |
| `--chain <сеть>` | сеть отелей: «Азимут», «Ибис», «Космос», «Хэмптон» |
| `--hotel-name <название>` | конкретный отель по названию: «есть ли места в Космосе» |
| `--bedrooms <N>` / `--beds <N>` | для квартир: сколько спален / кроватей не меньше |
| `--bed double` / `--bed separate` | одна большая кровать / раздельные кровати |
| `--room-size <м²>` | номер или квартира не меньше стольких метров |
| `--superhost` | квартиры только от проверенных хозяев с отличными отзывами |

**Питание, удобства, оплата**

| Аргумент | Что значит |
|---|---|
| `--breakfast` | с завтраком (или лучше) |
| `--meal <вид>` | `half-board` полупансион, `full-board` полный пансион, `all-inclusive` всё включено |
| `--amenities <список>` | через запятую: `pool` бассейн, `parking` парковка, `pets` можно с животными, `gym` спортзал, `spa` спа, `jacuzzi` джакузи, `kitchen` кухня, `ac` кондиционер, `balcony` балкон, `view` с видом, `beach` пляж, `transfer` трансфер из аэропорта, `kids` для детей, `wifi` интернет, `washer` стиральная машина, `private-bathroom` своя ванная, `accessible` для людей с инвалидностью, `smoking` можно курить, `ev-charger` зарядка электромобиля, `ski` у горнолыжки, `business` для деловой поездки |
| `--free-cancel` | с бесплатной отменой |
| `--pay-at-hotel` | оплата на месте, в отеле |
| `--no-card` | бронь без банковской карты |
| `--no-deposit` | без залога |
| `--limit <N>` | сколько вариантов вернуть: по умолчанию 5, по просьбе до 20 («покажи десять вариантов») |
| `--skip <N>` | «покажи ещё»: повтори тот же вызов со всеми теми же флагами и `--skip` = сколько уже показано (число из строки `MORE`) |

Требования сочетай. «Недорогой отель у Павелецкого вокзала с 27 по 29 сентября, чтобы можно было с
собакой» → `["--city", "Москва", "--checkin", "2026-09-27", "--checkout", "2026-09-29", "--near", "Павелецкий вокзал", "--type", "hotel", "--amenities", "pets", "--sort", "cheap"]`.
Город для `--near` — тот, где это место; вокзалы и аэропорты Москвы ищи с `--city Москва`.

Даты («на выходные», «с пятницы на воскресенье», «на майские») переводи в `YYYY-MM-DD` сам по
текущей дате из контекста. Даты не названы — уточни одним вопросом: без дат цен нет. Число
гостей не названо — считай двоих и не переспрашивай.

## Что возвращает скрипт

Строки с табуляцией как разделителем:

- `SEARCH⇥город⇥заезд⇥выезд⇥ночей⇥гостей⇥сколько вариантов доступно⇥порядок⇥какие фильтры применились`;
- `NEAR⇥место⇥тип` — искали рядом с этим местом; расстояние в `HOTEL` — до него;
- `HOTEL⇥название⇥тип⇥звёзды|-⇥рейтинг (отзывов)|-⇥цена за всё⇥цена за ночь⇥расстояние⇥метро|-⇥номер⇥питание⇥отмена⇥оплата⇥ссылка`.
  Расстояние — до места из `NEAR`, а без него до центра города;
- `NOT_APPLIED⇥…` — это требование применить не удалось (например, район не нашёлся): скажи об этом;
- `PLACE_UNKNOWN⇥…` — место для `--near` не нашлось в этом городе: уточни, что имелось в виду;
- `MORE⇥…` — вариантов больше, чем показано: если человек просит ещё, вызови скилл снова с `--skip` из этой строки;
- `LINK_ALL⇥ссылка` — вся выдача Островка на эти даты;
- `NO_RESULTS⇥…` — под требования ничего нет или все варианты уже показаны;
- `CITY_UNKNOWN⇥…` — город не найден;
- `NOTE⇥…` — напоминание про цены;
- строка с `Error:` — Островок недоступен или даты неверные.

## Как отвечать

- В Телеграме пиши простым текстом: без звёздочек, решёток и ссылок вида [текст](адрес) — Телеграм их не отображает. Ссылку ставь как есть, отдельной строкой.
- Говори обычными словами. Не используй «живые цены», «кэш», «планка», «выдача», «скилл», «на момент поиска» — так люди не говорят.
- Голосом коротко: два-три варианта. Для каждого — название, чем хорош по запросу человека,
  цена за ночь и рейтинг. «Мини-отель Стерео, полтора километра от центра, рейтинг восемь и
  шесть, около двух тысяч за ночь». Не зачитывай ссылки, адреса и полные названия номеров.
- Цену называй по-человечески и округляй: 11 520 → «около одиннадцати с половиной тысяч за ночь».
  Если человек спрашивал про бюджет на всё время, назови и цену за всё.
- Бесплатную отмену упоминай, если она есть: это важно при бронировании заранее.
- В конце одной фразой: цены на сегодня, при бронировании могут немного измениться. Предложи
  прислать ссылки. Голосом — отправь их текстом через `SendMessageToChannel` в telegram: ссылку
  на каждый названный вариант и `LINK_ALL`.
- В переписке (Telegram) списком: название, рейтинг, цена за ночь и за всё, до центра, отмена и под
  каждым отелем его ссылка из строки `HOTEL`. `LINK_ALL` — только в конце, как «все варианты».
- `NO_RESULTS` — скажи, что под такие условия ничего нет, и предложи смягчить одно условие
  (поднять бюджет, убрать звёзды или завтрак).
- `CITY_UNKNOWN` — переспроси город.
- `Error:` — скажи, что поиск отелей сейчас недоступен, без технических деталей.

## Ограничения

- Скилл ищет и даёт ссылку, но не бронирует и не платит. Бронирование — на Островке по ссылке.
- Цены с Островка на сегодня, итоговая цена — при бронировании на сайте.
- Скилл работает через поиск сайта Островка, а не через партнёрский API: если Островок поменяет
  сайт, поиск может перестать работать. Тогда отвечай по `Error:` и предлагай ссылку позже.
- Поезда — скилл `train-tickets`, авиабилеты — `avia-tickets`. Если человек планирует поездку целиком
  («съездить в Казань на выходные: дорога и жильё»), вызови и транспорт, и этот скилл.
